# 한국언론학보 규정 안내 페이지 — 홈페이지 담당자용 설치 안내

한국언론학보 연구윤리규정과 학보 규정 개정 내용을 학회원께 안내하는 정적 웹페이지입니다.
**폴더 전체를 서버에 올리면 끝**이며, 서버 프로그램(PHP·Java)이나 데이터베이스는 필요하지 않습니다.
모든 링크가 상대경로라서 어느 주소(폴더)에 올려도 그대로 동작합니다.

## 1. 올리는 방법

1. 이 폴더(`kjjc-guide`) **전체를 폴더 구조 그대로** 웹서버의 원하는 경로에 올립니다.
   - 예: `https://comm.or.kr/kjjc-guide/` → 접속 시 `index.html`이 열립니다.
   - 폴더 이름은 바꿔도 되지만, 폴더 안의 구조(`docs`, `media`, `pages` 등)는 바꾸지 마세요.
2. 주소로 접속해 아래 「4. 확인 목록」대로 점검합니다.
3. 학회 홈페이지의 학술지 정보 페이지(`/academic/journal/1/1.do`) 또는 공지사항 등에서 이 주소로 링크를 걸어 주세요.

정적 폴더를 올리기 어려운 구조라면, 같은 폴더를 별도 경로나 하위 도메인(예: `kjjc.comm.or.kr`)에 올려도 됩니다.

## 2. 폴더 구성

```
kjjc-guide/
├─ index.html                          안내 페이지 본문 (여기서 모든 자료로 연결)
├─ assets/fonts/PretendardVariable.woff2   글꼴 (본문 페이지용, 내장)
├─ docs/                               내려받는 문서
│   ├─ research-ethics-regulations.pdf         학술지 연구윤리규정
│   ├─ kjjc-regulations.pdf                    한국언론학보 규정
│   ├─ author-guidelines.pdf                   한국언론학보 논문 작성 지침 (2026.09.10)
│   └─ author-checklist-template-20261012.hwp  저자점검표 및 템플릿 (최신 20261012)
├─ media/
│   ├─ invitation.mp4                  안내 영상 (약 23MB, 1280×720, H.264/AAC)
│   └─ poster.jpg                      영상 대표 이미지
└─ pages/                              요약·매뉴얼 웹페이지 4종
    ├─ journal-changes/   한국언론학보, 무엇이 달라지나
    ├─ faq-editor/        편집위원장에게 묻다
    ├─ editorial-manual/  편집위원회 매뉴얼
    ├─ reviewer-manual/   심사위원 매뉴얼
    └─ _vendor/           인포그래픽 구동에 필요한 스크립트 (react, react-dom, babel)
```

## 3. 서버 설정 참고

- **영상(mp4)**: 영상을 건너뛰며 볼 수 있도록 서버가 부분 요청(Range, `Accept-Ranges`)을 지원하면 좋습니다. 대부분의 웹서버는 기본 지원합니다. 용량이 부담되면 이 영상만 학회 영상 서버나 유튜브에 두고, `index.html`의 `<video>` 태그 한 곳만 교체해도 됩니다.
- **HWP 파일**: 브라우저에서 열리지 않고 내려받아지도록, 확장자 `.hwp`가 일반 파일 다운로드로 처리되는지 확인해 주세요.
- **글꼴(woff2)**: `.woff2` 파일이 정상 제공되어야 합니다. 서버에서 막혀 있으면 기본 글꼴로 대체되어 보입니다.
- **보안 정책(CSP)을 쓰는 경우**: 안내 페이지와 인포그래픽은 페이지 안의 스크립트·스타일을 사용하고, 인포그래픽(`Main.dc.html`)은 Babel이 코드를 변환하므로 `unsafe-eval`이 필요합니다. 정책 때문에 인포그래픽이 비어 보이면 이 부분을 확인해 주세요. 본문 페이지(`index.html`)와 텍스트 페이지는 영향이 없습니다.
- **외부 연결**: 본 패키지가 외부 서버에 의존하는 것은 **Google Fonts**(텍스트 페이지 4종과 인포그래픽의 글꼴)뿐입니다. 연결이 막혀도 시스템 기본 글꼴로 정상 표시됩니다. 이 외의 스크립트·이미지·글꼴은 모두 폴더 안에 들어 있습니다.

## 4. 확인 목록

- [ ] `index.html`이 열리고, 영상이 재생된다 (대표 이미지가 보이고 재생·탐색이 된다)
- [ ] 「한국언론학보, 무엇이 달라지나」 등 요약·매뉴얼 4개 링크가 열린다
- [ ] 각 요약·매뉴얼 페이지의 「인터랙티브 인포그래픽 보기」 버튼이 열리고 내용이 보인다
- [ ] PDF 3종이 열리고, 저자점검표 및 템플릿(HWP)이 내려받아진다
- [ ] 휴대전화 화면에서도 가로 스크롤 없이 보인다

## 5. 저자점검표 및 템플릿을 새 버전으로 바꿀 때

저자점검표 및 템플릿은 개정될 때마다 최신 버전만 안내해야 합니다. 편집위원회에서 새 파일을 보내면 다음 순서로 교체해 주세요.

1. `docs/`의 기존 HWP 파일을 지우고 새 파일을 같은 폴더에 넣습니다. (파일명 예: `author-checklist-template-YYYYMMDD.hwp`)
2. `index.html`을 텍스트 편집기로 열어 `20261012`를 검색합니다. 3곳(안내 문구, 카드의 `최신` 표시, 파일 링크)이 나옵니다. 안내 문구에는 `2026년 10월 12일자`라는 날짜 표기도 함께 있습니다. 이 4가지를 모두 새 날짜·새 파일명으로 바꿉니다.
3. 저장 후 서버에 덮어쓰고, 페이지에서 내려받아지는지 확인합니다.
